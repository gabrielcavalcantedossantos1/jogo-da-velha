# Jogo da Velha 🎮

Projeto de Jogo da Velha desenvolvido em React, com foco em lógica, organização de código e experiência do usuário.

## 🧠 Funcionalidades
- IA com 3 níveis de dificuldade (Fácil, Médio e Difícil)
- Modo difícil utilizando o algoritmo Minimax
- Interface responsiva

## 🚀 Tecnologias utilizadas
- React
- JavaScript
- HTML
- CSS
